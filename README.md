# Calculadora de IMC

Programa de terminal em Java que calcula o Índice de Massa Corporal (IMC) a partir do peso e da altura informados.

## O que o projeto usa
- Java
- Leitura de dados com `Scanner`
- Variáveis, tipos e operações aritméticas
- Formatação da saída com `printf`

## Como rodar
Requisito: JDK instalado (Java 17 ou superior).

    javac Main.java
    java Main

## Exemplo

    Nome: Ana
    Peso (kg): 70
    Altura (m): 1,75

    === Resultado de Ana ===
    IMC: 22,9
